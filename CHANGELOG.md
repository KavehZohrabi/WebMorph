# Changelog

Notable changes to WebMorph are recorded here.

## 0.1.0 - Unreleased

Initial public-release candidate, including:

- Lightweight asynchronous HTTP/HTTPS fetching and terminal reading UI.
- HTML normalization, forms, tabs, navigation, and URL safety checks.
- SQLite storage layer, trusted built-in plugin registry, and GitHub plugin.
- Optional, explicitly selected Chromium backend.
